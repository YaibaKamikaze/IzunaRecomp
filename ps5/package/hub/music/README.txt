The hub's theme. The first .wav here (in name order) plays behind the hub
while SETTINGS > Game > Hub music is on; replace it with any WAV (16-bit PCM
or 32-bit float, 44.1 or 48 kHz). A smpl chunk's loop start, if the file has
one, is where the music loops back to, so an opening plays once.

theme.wav is "The Hero" from the Ninja Gaiden II soundtrack (Koei Tecmo),
cut to its opening and one 84-second cycle by ps5/tools/make_hub_music.py;
the owner chose it. Replace it with music you may share before publishing a
release if that matters for where it goes.
