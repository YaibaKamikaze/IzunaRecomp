Ninja Gaiden II - IzunaRecomp @VERSION@ for Android
==================================================

A native recompilation of Ninja Gaiden II (Xbox 360), drawn by the Kasumi
Renderer (Vulkan). No emulator and no game files come with it: you need your
own copy of the game.

Needs: Android 11 or newer on a 64-bit ARM device with Vulkan - made for
Snapdragon (Adreno) devices, e.g. the Snapdragon 8 Gen 2 and newer. A
controller: the game is played with one.


Starting
--------
1. Install the APK (allow installing from this source when Android asks).
2. Start IzunaRecomp and allow "All files access" on the screen it opens:
   the game reads your copy of Ninja Gaiden II from your device's storage.
3. Copy your extracted game (the folder with default.xex, the .ng2 archives
   and the videos, about 6.7 GB) anywhere on the device or its SD card.
4. The hub asks for your game folder: choose that folder. It is remembered.
5. START GAME.


The IzunaRecomp folder
----------------------
Settings, logs, mods, DLC and saves to import live in the IzunaRecomp folder
at the top of your device's storage (/storage/emulated/0/IzunaRecomp):

  logs/          the newest ng2_*.log - send it with any report
  mods/          mods (see the README there)
  DLC/           your Xbox 360 DLC packages
  Saves Import/  Xbox 360 saves to import


Controls
--------
A controller, as on the Xbox 360: Cross / A, Circle / B, Square / X,
Triangle / Y, the shoulder buttons and triggers, Start / Options and the
sticks. Touch controls are off.
