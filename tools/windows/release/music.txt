The hub's music (optional).

Put a .wav file here and it plays behind the hub while SETTINGS > Game > Hub
music is on (the first one, in name order). 16-bit PCM or 32-bit float,
44.1 or 48 kHz. A smpl chunk's loop start, if the file has one, is where the
music loops back to, so an opening plays once.

No music comes with IzunaRecomp.
